# 오늘의 패치 · 아이온2

아이온2 이용자가 업데이트 공지의 핵심, 직업별 변경점, 이벤트와 패치 후 할 일을 빠르게 확인할 수 있도록 구성한 웹 UI 프로토타입입니다. Figma의 메인 홈과 게임별 소식 화면 구조를 바탕으로 만들었습니다.

## 로컬에서 실행하기

Node.js 18 이상이 설치되어 있으면 추가 패키지 설치 없이 실행할 수 있습니다.

```bash
node server.js
```

브라우저에서 [http://localhost:4173](http://localhost:4173)을 여세요. 다른 포트를 사용하려면 `PORT=5000 node server.js`로 실행합니다. Windows PowerShell에서는 `$env:PORT=5000; node server.js`를 사용할 수 있습니다.

## 포함한 화면과 동작

- 메인 홈: 최신 소식, 오늘 할 일, 출처와 분석 상태
- 업데이트 피드: 키워드 검색, 유형 필터, 정렬
- 업데이트 브리핑: 요약, 직업별 변경점, 공식 출처 상태, 후속 체크리스트
- 할 일 체크, 북마크와 검색 조건을 브라우저 `localStorage`에 저장
- 모바일·태블릿 반응형 레이아웃
- 로그인과 정보 신고를 위한 프로토타입 모달

현재 표시되는 공지 제목·요약은 디자인용 예시입니다. 실제 아이온2 공지 수집, AI 분석, 계정 로그인, 신고 저장 API는 연결되어 있지 않습니다.
