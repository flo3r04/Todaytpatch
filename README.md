# 오늘의 패치 (Todaypatch)

게임별 공식 소식, 패치 분석, 일정과 커뮤니티를 한곳에서 확인하는 반응형 웹앱입니다. 현재 실제 크롤링과 AI 분석을 제공하는 게임은 아이온2입니다. 도깨비의 세계와 템빨은 검색·팔로우 화면에 포함되어 있지만, 공식 소식 연동 상태는 아래의 지원 범위를 확인해 주세요.

## 현재 지원 범위

| 게임·기능 | 현재 동작 | 데이터 범위 |
| --- | --- | --- |
| 아이온2 | 공식 게시물 검색, 분류, AI 요약·분석, 일정 추출 | 공지, 업데이트, CM 아지트 |
| 도깨비의 세계 | 게임 허브와 게시판 화면 예시 | 화면 확인용 예시 콘텐츠이며 공식 데이터 크롤링은 연결되지 않음 |
| 템빨: 오버기어드 | 게임 검색, 팔로우, 출시 카운트다운 | 출시일은 코드에 입력된 값이며 공식 소식 연동은 연결되지 않음 |
| 커뮤니티 | 게임별 게시글, 댓글, 좋아요, 신고와 운영자 검토 | 같은 데이터베이스를 사용하는 모든 방문자에게 공개 |

## 기능 안내

### 1. 게임 찾기와 홈 화면

- 검색창은 게임 이름과 등록된 별칭을 검색합니다. 아이온2, 도깨비의 세계, 템빨을 찾을 수 있습니다.
- 검색창을 선택하면 최근 검색어를 최대 5개까지 보여주며, 검색 기록은 브라우저에 저장됩니다.
- 검색 결과에서 게임 이름을 누르면 해당 게임 화면으로 이동하고, **팔로우**를 누르면 관심 게임에 추가됩니다.
- 홈에는 최신 패치 브리핑, 출시 카운트다운, 공략 후보, 인기 게시글, 팔로우한 게임 게시글과 커뮤니티 글이 표시됩니다.
- 홈의 팔로우 게임 아이콘은 해당 게임으로 이동합니다. 아이콘을 마우스 오른쪽 버튼으로 누르거나 모바일에서 길게 누르면 팔로우를 해제할 수 있습니다.
- 공략·인기 게시글 순위는 서버 전체 이용자 통계가 아닙니다. 현재 브라우저의 열람·북마크·읽음 기록과 게시물 내용으로 계산합니다.

### 2. 아이온2 소식 목록

- 아이온2 메뉴에서 **전체 소식, 공지, 업데이트, CM 아지트**를 따로 확인할 수 있습니다.
- 제목과 요약에 대한 검색과 게시물 유형 필터를 제공합니다.
- 목록에는 게시물 제목, 유형, 출처, 게시일을 표시합니다. 상세 본문은 공식 사이트 링크에서 확인할 수 있습니다.
- 게시물을 열면 읽음 상태가 브라우저에 저장됩니다.

### 3. 게시물 상세와 AI 분석

- 상세 페이지는 **전체 내용 요약, 이용자 관점 분석, 주요 제목별 분석, 중요 정보, 공식 원문 링크**를 제공합니다.
- 날짜, 시간, 수량, 대상, 예외, 제한과 절차처럼 사용자가 놓치기 쉬운 항목을 파트별로 정리합니다.
- 크롤러는 공식 게시물의 원문을 분석 요청에 사용하지만, 원문 전체를 사이트 데이터에 보관하지 않습니다. 저장되는 것은 게시물 메타데이터, 요약, 분석, 중요 항목, 일정과 원문 링크입니다.
- AI가 놓친 조건이나 잘못 해석한 내용이 있을 수 있으므로 실제 신청·수령 전에는 공식 원문을 확인해 주세요.
- **이 공지로 질문하기**와 **토론 시작하기**는 원문 링크와 선택한 AI 분석 항목이 미리 연결된 커뮤니티 글쓰기 화면을 엽니다.
- 상세 화면의 정보 신고 양식은 현재 입력 내용을 저장하거나 운영자에게 전송하지 않는 프로토타입입니다. 커뮤니티 게시글 신고와는 별도 기능입니다.

### 4. 패치 후 할 일과 일정 캘린더

- **패치 후 할 일**은 아이온2 AI 분석과 일정 단서에서 업데이트, 이벤트, 보상, 기간 관련 행동 후보를 규칙 기반으로 추천합니다.
- 할 일의 완료 여부는 브라우저에 저장되며, 로그인 계정과 동기화되지 않습니다.
- 대시보드 캘린더는 팔로우한 게임의 수집 데이터에서 이벤트 시작일, 종료일, 보상 마감일, 서버 이전 일정 등을 표시합니다.
- 일정은 크롤링한 AI 분석에 날짜가 명시된 경우에만 표시됩니다. 날짜가 없거나 AI가 추출하지 못한 일정은 나타나지 않을 수 있습니다.
- 일정 항목을 누르면 근거 게시물 상세로 이동합니다.

### 5. 공지 질문 챗봇

- 화면 오른쪽 아래의 **질문** 버튼을 누르면 공지 질문 창이 열립니다.
- 사용자가 입력한 핵심어와 게시물 제목, 요약, 분석, 파트별 중요 항목, 날짜·조건·보상 데이터를 가중치 기반으로 비교해 관련 근거와 게시물 링크를 보여줍니다.
- 현재 챗봇은 외부 생성형 AI에 질문을 보내지 않습니다. 수집된 분석 데이터에서 일치하는 근거를 찾는 검색형 기능이며, 관련 근거가 부족하면 찾지 못했다고 안내합니다.
- 질문과 대화 내역은 현재 페이지가 유지되는 동안만 보관됩니다.

### 6. 팔로우, 북마크, 읽음과 알림

- 팔로우한 게임은 홈 바로가기와 대시보드에 표시됩니다.
- 게시물 상세에서 북마크를 추가·해제하고, 북마크 페이지에서 저장한 소식을 모아볼 수 있습니다.
- 게시물의 읽음 표시와 최근 게임 검색어도 관리할 수 있습니다.
- 팔로우한 아이온2에 새로운 크롤링 데이터가 반영되면 앱 안 알림을 갱신합니다. 브라우저 알림은 사용자가 별도로 허용한 경우에만 표시됩니다.
- 알림은 페이지 방문 또는 새로고침 때 확인합니다. 백그라운드 푸시, 이메일 알림과 자동 정기 크롤링은 제공하지 않습니다.

### 7. 대시보드와 개인 메모

- 대시보드에서 팔로우한 게임, 북마크, 팔로우한 게임의 커뮤니티 글, 일정 캘린더와 내가 작성한 개인 글을 확인합니다.
- 대시보드의 개인 글은 브라우저 안에 저장하는 메모입니다. 게시판에 공개되는 커뮤니티 글과 다릅니다.
- 팔로우, 북마크, 읽음 상태, 할 일, 최근 검색어와 개인 메모는 현재 브라우저 `localStorage`에 저장됩니다. 계정에 로그인해도 다른 기기로 동기화되지 않습니다.

### 8. 커뮤니티와 계정

- 게임별 게시판에서 **자유게시판, 질문, 공략, 토론** 글을 최신순 또는 인기순으로 보고, 게임·유형·키워드로 필터링할 수 있습니다.
- 이메일과 비밀번호로 가입·로그인한 뒤 게시글, 댓글, 좋아요와 신고를 사용할 수 있습니다.
- 게시글은 제목 100자, 본문 5,000자, 태그 최대 8개로 제한합니다. 작성자는 자신의 글을 수정·삭제할 수 있습니다.
- 공식 공지에서 시작한 글은 원문 링크와 선택한 AI 요약·분석 항목을 연결할 수 있습니다. 분석 내용에서 태그 후보를 제안합니다.
- 비밀번호는 원문으로 저장하지 않고 scrypt 해시로 저장합니다. 로그인 실패가 일정 횟수 누적되면 해당 이메일의 로그인을 잠시 제한합니다. 게시글·댓글에도 반복 작성 제한이 있습니다.
- Vercel에 연결된 PostgreSQL에는 계정, 세션, 커뮤니티 게시글, 댓글, 좋아요, 신고와 커뮤니티 알림을 저장합니다. 같은 운영 데이터베이스를 사용하는 기기라면 동일한 계정으로 커뮤니티 기록을 이어서 볼 수 있습니다.
- 이전 게스트 세션이 브라우저에 남아 있다면 **계정 연결**로 이메일 계정을 등록해 기존 커뮤니티 글과 댓글을 보존할 수 있습니다.
- 이메일 인증, 비밀번호 재설정, 소셜 로그인은 아직 제공하지 않습니다. 비밀번호를 안전한 곳에 보관해 주세요.
- 이미지는 첨부할 수 없으며 실시간 채팅도 제공하지 않습니다.

### 9. 신고 검토와 화면 설정

- 커뮤니티 게시글 신고는 데이터베이스에 접수되며, 운영자는 관리자 토큰으로 신고를 확인하고 게시글 유지·숨김·복구를 처리할 수 있습니다.
- 운영자 토큰은 서버의 `TODAYPATCH_ADMIN_TOKEN` 환경 변수와 일치해야 합니다.
- 라이트·다크 모드, 모바일 메뉴와 첫 방문 튜토리얼을 제공합니다. 튜토리얼은 다음·이전 단계로 이동하며, 자동 표시를 끌 수 있습니다.

## 데이터 저장 위치

| 데이터 | 브라우저에서 직접 열기·로컬 서버 | Vercel 배포 | 기기 간 공유 |
| --- | --- | --- | --- |
| 게임 팔로우, 북마크, 읽음, 할 일, 최근 검색, 개인 메모, 테마 | 브라우저 `localStorage` | 브라우저 `localStorage` | 공유되지 않음 |
| 크롤링한 아이온2 소식과 AI 분석 | `data/aion2.js` 정적 파일 | 배포된 정적 파일 | 배포 내용이 모든 방문자에게 동일 |
| 계정·세션·커뮤니티 글·댓글·반응·신고 | `.private/community.json` | 연결된 PostgreSQL | 동일 저장소에 연결된 배포·기기에서 공유 |

로컬 JSON 저장소와 Vercel PostgreSQL은 별개이며 자동으로 서로의 데이터를 이전하지 않습니다. `.private`, `.env`, `.env.local`은 Git에 올리지 마세요. 저장소의 [`.env.example`](.env.example)은 설정 변수 이름 예시이며 실제 비밀 값을 넣지 않습니다.

## 로컬에서 실행하기

### 정적 화면만 열기

`index.html`을 브라우저에서 열면 정적 화면과 브라우저 저장 기능을 확인할 수 있습니다. `file://` 방식에서는 커뮤니티 계정·게시글 API를 사용할 수 없습니다.

### 로컬 서버로 실행하기

Node.js 18 이상이 필요합니다. 저장소 폴더에서 실행하세요.

```powershell
cd C:\Users\user\Desktop\Todaypatch
npm start
```

브라우저에서 [http://localhost:4173](http://localhost:4173)을 엽니다. 포트를 변경하려면 아래처럼 실행할 수 있습니다.

```powershell
$env:PORT = "5000"
node server.js
```

로컬 서버는 커뮤니티 계정과 게시물을 `.private/community.json`에 저장합니다. 이 파일은 Git에서 제외됩니다. 로컬 서버 데이터는 Vercel 데이터베이스와 동기화되지 않습니다.

### Vercel 개발 모드

Vercel 프로젝트를 연결한 다음 프로젝트 환경 변수를 내려받고 개발 서버를 실행할 수 있습니다.

```powershell
npx vercel link
npx vercel env pull .env.local
npx vercel dev
```

`.env.local`을 공유하거나 Git에 커밋하지 마세요.

## 아이온2 크롤링과 AI 분석

크롤러는 아래 공식 게시판에서 기준일 이후 게시물을 수집합니다.

- [공지](https://aion2.plaync.com/ko-kr/board/notice/list)
- [업데이트](https://aion2.plaync.com/ko-kr/board/update/list)
- [CM 아지트](https://aion2.plaync.com/ko-kr/board/cm_story/list)

CM 아지트는 아이온2 전용 소식입니다. 다른 게임에는 이 게시판 데이터를 표시하지 않습니다.

### API 키 설정

1. [Google AI Studio API 키 페이지](https://aistudio.google.com/apikey)에서 키를 발급받습니다.
2. Windows 사용자 환경 변수에 이름 `GEMINI_API_KEY`, 값에 발급받은 키를 저장합니다.
3. 새 PowerShell을 열고 아래 명령으로 사용자 환경 변수의 키를 현재 터미널에 불러옵니다. 키 자체는 화면에 출력되지 않습니다.

```powershell
$env:GEMINI_API_KEY = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'User')
if (-not $env:GEMINI_API_KEY) { throw 'GEMINI_API_KEY를 사용자 환경 변수에 설정해 주세요.' }
```

키를 소스 코드, `.env.example`, GitHub 또는 채팅에 붙여 넣지 마세요. 크롤링 작업은 `GEMINI_API_KEY`를 사용하며 OpenRouter를 거치지 않습니다.

### 크롤링 실행

```powershell
cd C:\Users\user\Desktop\Todaypatch
npm run crawl
```

크롤러는 `gemma-4-31b-it` 모델을 Google Gemini API로 직접 호출합니다. 게시물 본문을 AI가 처음부터 끝까지 분석한 다음 구조화된 JSON 응답을 검증해 `data/aion2.js`에 기록합니다.

- 기본 수집 기준일은 한국 시간 `2026-11-18`입니다. 기준일은 `$env:AION2_CRAWL_SINCE = "YYYY-MM-DD"`로 변경할 수 있습니다.
- AI는 게시물 한 건씩 분석합니다. 일반 요약은 5~8문장, 긴 업데이트는 8~14문장까지 작성하도록 요청하고, 파트별 변경·영향·수치·대상·예외·절차·일정도 별도로 추출합니다.
- API 요청은 게시물별로 순차 실행합니다. 429 또는 5xx 일시 오류는 최대 세 번 대기 후 재시도하며, 형식이 맞지 않는 응답은 같은 모델로 한 번 더 요청합니다.
- 개별 요청 방식은 요약 품질을 높이기 위한 설정이며 전체 크롤링 시간이 길어지고 무료 모델의 사용량 제한이나 503 오류가 발생할 수 있습니다.
- 크롤링 또는 분석이 실패하면 최종 데이터 파일을 갱신하지 않아 이전 데이터를 유지합니다.
- 사이트는 저장된 `data/aion2.js`를 보여주는 정적 앱입니다. Vercel 배포 과정에서 크롤링이나 AI 요약이 자동 실행되지 않습니다. 새 분석 결과를 공개하려면 데이터 변경도 검토해 커밋·푸시하고 다시 배포해야 합니다.

## Vercel 배포와 데이터베이스 설정

정적 파일은 저장소 루트에서 제공하며, 커뮤니티 API는 `api/community.js` Vercel 함수가 처리합니다. 배포 환경에서는 `.private/community.json`을 사용할 수 없으므로 PostgreSQL 데이터베이스를 연결해야 합니다.

1. Vercel에서 저장소를 프로젝트로 연결하고 Framework Preset은 **Other**로 둡니다.
2. Vercel Marketplace에서 Neon 또는 다른 PostgreSQL 제공자를 프로젝트에 설치·연결합니다. [Vercel Postgres 안내](https://vercel.com/docs/postgres) · [Marketplace 저장소 안내](https://vercel.com/docs/marketplace-storage)
3. Todaypatch 프로젝트의 **Settings → Environment Variables**에서 Production 환경에 DB 연결 문자열이 있는지 확인합니다. API가 인식하는 변수 이름은 `DATABASE_URL`, `POSTGRES_URL`, `POSTGRES_PRISMA_URL`, `NEON_DATABASE_URL`입니다.
4. 연결 문자열이 없으면 DB 제공자가 안내하는 pooled PostgreSQL 연결 문자열을 `DATABASE_URL`로 등록합니다. 연결 정보 값은 공개하거나 채팅으로 공유하지 마세요.
5. 선택 사항으로 `TODAYPATCH_ADMIN_TOKEN`에 운영자만 아는 긴 임의 값을 등록합니다.
6. 환경 변수를 추가·수정했다면 최신 Production 배포를 다시 실행합니다. Vercel 환경 변수 변경은 새 배포부터 적용됩니다 ([환경 변수 설정 안내](https://vercel.com/docs/environment-variables)).
7. 배포된 사이트에서 **로그인 → 계정 만들기**를 진행합니다. 첫 API 요청 때 계정·세션·게시글 등 테이블과 기존 계정 테이블의 이메일·비밀번호 열이 자동으로 준비됩니다.

Vercel 계정과 커뮤니티 기록은 연결된 데이터베이스에 저장됩니다. 팔로우와 북마크 등 브라우저 개인 설정은 현재 DB에 저장되지 않습니다. 로컬 계정과 Vercel 계정도 자동으로 합쳐지지 않습니다.

## 저장소 구조

| 경로 | 역할 |
| --- | --- |
| `index.html` | 앱 진입점, 메타데이터, CSS·JavaScript 로드 |
| `app.js` | 화면 라우팅, 홈·게임·상세·대시보드·캘린더·알림·챗봇 |
| `community.js` | 계정 화면, 게임별 커뮤니티 UI와 API 연결 |
| `api/community.js` | Vercel용 PostgreSQL API, 인증, 글·댓글·반응·신고 |
| `server.js` | 로컬 정적 서버와 `.private/community.json` 기반 커뮤니티 API |
| `scripts/crawl-aion2.js` | 아이온2 게시판 크롤링, Gemma 분석과 데이터 생성 |
| `data/aion2.js` | 배포 시 사용하는 아이온2 소식과 분석 결과 |
| `styles.css` | 라이트·다크 모드, 반응형 화면과 컴포넌트 스타일 |

프런트엔드는 HTML·CSS·브라우저 JavaScript로 구성되어 별도 번들 빌드가 없습니다. Vercel API용 PostgreSQL 드라이버는 `pg` 의존성을 사용합니다.

## 현재 한계와 검수 결과

- 실제 공식 게시물 크롤링은 아이온2의 공지, 업데이트, CM 아지트만 지원합니다.
- 도깨비의 세계 화면에 있는 게시물은 동작과 레이아웃 확인용 예시 데이터입니다. 공식 정보로 오해하지 않도록 화면의 예시 안내를 확인하세요.
- 템빨 출시일과 게임 정보는 코드 카탈로그 값이며, 공식 일정 변경을 자동 추적하지 않습니다.
- 챗봇은 AI 모델을 실시간 호출하지 않는 키워드 검색형입니다. 최신 질문 능력, 원문 인용 정확도와 여러 게시물에 걸친 복합 추론은 제한적입니다.
- 대시보드의 개인 글과 할 일 완료 상태는 공개 게시판 글이나 DB 계정 글이 아닙니다. 브라우저 저장소에서 삭제되거나 다른 기기와 동기화되지 않을 수 있습니다.
- 공식 게시물의 정보 신고는 현재 실제 접수되지 않습니다. 게시판의 커뮤니티 글 신고만 DB에 저장되고 운영자 검토 화면에 표시됩니다.
- 패치 데이터는 수동 크롤링 후 재배포해야 합니다. 크롤링 예약과 브라우저가 닫힌 상태의 푸시 알림은 설정되어 있지 않습니다.
- 저장소에 자동 테스트 스크립트는 아직 없습니다. 배포 전 JavaScript 구문 확인, 계정 가입·로그인, 게시글 CRUD, 일정·알림 확인을 위한 자동 회귀 테스트를 추가하면 변경 안정성을 높일 수 있습니다.

## 다음에 추가하면 좋은 기능

아래는 이미 구현된 기능이 아니라, 현재 구조와 서비스 차별화를 기준으로 한 제안입니다.

1. **계정 기반 개인 설정 동기화:** 팔로우, 북마크, 읽음, 할 일과 개인 메모를 PostgreSQL에 저장합니다. 로그인 전 브라우저 데이터는 계정에 합칠 수 있도록 가져오기·중복 정리 화면을 함께 두면 좋습니다.
2. **패치 간 변경 비교:** 이전 버전과 새 업데이트를 직업·스킬·콘텐츠별로 비교해 바뀐 수치, 신규·삭제 항목과 이용자 영향만 보여줍니다. 일반 공지 모음과 구분되는 핵심 기능이 될 수 있습니다.
3. **근거가 보이는 챗봇:** 답변에 사용한 게시물의 파트·항목과 공식 원문 링크를 각각 연결하고, 근거가 약할 때는 답변을 보류하도록 개선합니다.
4. **일정 알림과 캘린더 내보내기:** 이벤트 마감 전 알림을 예약하고 ICS 파일로 내보냅니다. 현재 방문 시 확인하는 알림과 수동 캘린더를 더 실용적으로 확장할 수 있습니다.
5. **데이터 검토 도구:** AI가 추출한 날짜·보상·조건을 운영자가 원문과 대조하고 수정·승인하는 화면을 둡니다. 수정 결과는 다음 크롤링에서 재사용해 반복 오류를 줄입니다.
