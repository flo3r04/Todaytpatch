# 오늘의 패치

게임을 검색해 선택한 뒤 업데이트, 직업별 변경점, 이벤트, 공략과 패치 후 할 일을 찾아볼 수 있는 정적 웹 UI 프로토타입입니다. 초기 지원 게임은 아이온2이며, Figma의 화면 구조와 Notion 서비스 기획의 1차 출시 범위를 참고했습니다.

## 로컬에서 실행하기

### Node.js 없이 바로 열기

파일 탐색기에서 `index.html`을 더블클릭하세요. 정적 화면과 검색·필터 기능을 바로 사용할 수 있습니다. CSS와 JavaScript 경로를 상대 경로로 지정해 `file://`에서도 열리도록 구성했습니다.

### 로컬 서버로 실행하기 (선택)

Node.js 18 이상이 설치되어 있으면 추가 패키지 설치 없이 실행할 수 있습니다.

```bash
node server.js
```

터미널 창을 켜둔 채 브라우저에서 [http://localhost:4173](http://localhost:4173)을 여세요. 다른 포트를 사용하려면 Windows PowerShell에서 `$env:PORT=5000; node server.js`로 실행합니다.

### 아이온2 최근 패치 날짜 갱신

Node.js 18 이상과 인터넷 연결이 있으면 프로젝트 폴더에서 `npm run crawl`을 실행하세요. 공식 아이온2 업데이트 게시판의 최신 업데이트 노트 날짜를 확인해 `data/aion2.js`를 갱신합니다. 크롤링이 실패하거나 업데이트 노트를 찾지 못하면 기존 데이터는 유지됩니다.

## 화면과 동작

- 메인 화면: 게임 검색과 아이온2 진입만 표시
- 아이온2 개요: 업데이트, 직업, 이벤트, 공략, 할 일 메뉴와 최근 정보 미리보기
- 정보별 화면: 키워드 검색, 유형 필터, 상세 화면 이동
- 상세 화면: 요약, 출처·버전·게시일 정보 구조, 분석·운영자 검토 상태
- 체크리스트 완료 표시와 소식 북마크를 브라우저 `localStorage`에 저장
- 정보 신고 양식, 모바일 메뉴, 반응형 레이아웃

메인 화면의 아이온2 최근 패치 날짜는 `npm run crawl`로 공식 업데이트 게시판에서 수집합니다. 업데이트·공략·이벤트 카드 본문과 요약은 화면 구조를 확인하기 위한 예시 데이터이며, 전체 공지 자동 수집, AI 분석, 계정 로그인·동기화, 신고 저장 API는 연결되어 있지 않습니다.
